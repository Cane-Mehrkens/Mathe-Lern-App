# Mathe-Lern-App
Mathe ist dreck, deswegen verstehe es mit dieser Lern App
https://mathe-lern-app.onrender.com

 MatheCoach

Start:
1. ZIP entpacken.
2. index.html doppelklicken.
3. Im Browser öffnen.

Die App ist eine reine Offline-Website.
Der Speicherstand funktioniert im gleichen Browser über localStorage.
Wenn du die Datei in einem anderen Browser/auf einem anderen Gerät öffnest, ist der Speicherstand dort neu.
